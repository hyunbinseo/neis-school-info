> [!WARNING]
> 학교기본정보는 정기적으로 점검되는 데이터가 아니다. 변경 사유가 없었다면 오래전 입력된 값이 그대로 남아있을 수 있다. (e.g. 휴원, 학교 형태 변경)

## 개발 동기

[나이스 교육정보 개방 포털](https://open.neis.go.kr)의 학교기본정보 API 명세는 각 출력 필드의 이름과 설명만 제공할 뿐, 실제 응답값의 형식은 정의하지 않는다. 필드가 `null`로 내려오는지 문자열로 내려오는지, 값이 없을 때 빈 문자열(`""`)인지 공백만 있는 문자열(`"  "`)인지는 명세만으로 알 수 없다.

## 데이터 유의사항

- [#1] 고등학교이면서 `고등학교일반전문구분명`이 `해당없음` 또는 `null`일 수 있다.
- [#4] `고등학교구분명`이 `일반고`인데도 `특수목적고등학교계열명` 값이 존재할 수 있다.
